## About Me

Backend Software Engineer with 10+ years of experience building web applications and backend systems with Golang, PHP, and Node.js. My work spans RESTful and GraphQL APIs, third-party integrations, event-driven architectures, and production systems for enterprise clients.

I enjoy working on systems from the ground up, improving existing architectures, and solving the problems that emerge when software meets real-world requirements. I care about clean code, maintainability, and engineering practices that make systems easier to evolve.

Outside my day job, I run [Kalsara Digital Studio](https://kalsara.id/), where I design and build websites and digital solutions that combine thoughtful design with solid engineering.

Based in Jakarta, Indonesia. Open to remote freelance work worldwide.
